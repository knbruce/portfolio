# Hospital Management System Database (HospitalDB)

A Microsoft SQL Server database designed for managing hospital records, medical staff, appointments, and patient details with database security and role-based access control.


- **Relational Data Model**: Tables for Patients, Doctors, Appointments, and Staging data.
- **Database Security**: Configured with Column Level Encryption and Transparent Data Encryption (TDE) utilizing Database Master Keys (DMK) and Certificates.
- **Access Control & Permissions**: Role-based permissions configured for application and staging users (`AppUser`, `StagingUser`).


- **Database Engine**: Microsoft SQL Server
- **Management Tool**: SQL Server Management Studio (SSMS)
